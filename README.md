# Quiz Application

## About the Project
The Quiz Application is a simple interactive website that allows users to answer multiple-choice questions and check their final scores.

## Features
- Multiple-choice questions
- Four answer options for each question
- Highlights correct and incorrect answers
- Automatic score calculation
- Displays final results
- Restart quiz option
- Simple and user-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start answering the questions!

## Project Structure
- index.html – Website structure
- style.css – Website design
- script.js – Quiz functionality
- README.md – Project documentation
